# Overview

Live overzicht van mijn publieke GitHub-projecten. Haalt repo-info dynamisch op via de GitHub API, zodat de pagina altijd actueel is zonder dat ik 'm hoef bij te werken.

**👉 [Open het overzicht](https://erikotn.github.io/Overview/)**

## Wat het doet

- Fetcht alle publieke repositories van mijn GitHub account in real-time
- Toont per repo: naam, beschrijving, taal, laatste update
- Linkt direct door naar de repo en (waar beschikbaar) de live demo

## Voor wie

Mezelf en wie nieuwsgierig is naar wat ik bouw. Werkt als minimal portfolio-pagina zonder onderhoud.
